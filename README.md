# 학원 입지 가이드

학원을 새로 여는 분들이 **어느 동네에서 열면 좋을지** 비교해 볼 수 있는 사이트입니다.
동네별 **학생 수**(초·중·고)와 **기존 학원 수**(수학, 영어, 입시·보습 전체)를 합쳐
"학원 1곳당 학생 수"를 계산하고, 경쟁이 덜한 동네부터 보여줍니다.

**서울 25개 구, 경기 31개 시·군, 인천 전체**를 다룹니다. 지역 안에서는 동·읍·면별로 비교합니다.

## 쓰는 공공데이터

| 무엇 | 어디서 | GitHub Secret 이름 |
| --- | --- | --- |
| 학원 목록 (주소, 분야, 교습과정) | [나이스 교육정보 개방포털](https://open.neis.go.kr) 학원교습소정보 API | `NEIS_API_KEY` |
| 학생 수 (학교별 재학생) | [학교알리미](https://www.schoolinfo.go.kr) OpenAPI 학년별·학급별 학생수 | `SCHOOLINFO_API_KEY` |

두 인증키 모두 무료입니다. 키는 저장소 **Settings → Secrets and variables → Actions**에 넣고, 코드나 파일에는 절대 적지 않습니다.

## 자동 업데이트

`.github/workflows/update-data.yml`이 **매달 5일** 두 API에서 최신 데이터를 받아 `data/` 아래 지역별 파일(예: `data/서울-노원구.json`, `data/경기-수원시.json`)과 `data/regions.json`을 새로 만들고 저장소에 저장합니다.
기다리지 않고 바로 돌리려면 저장소의 **Actions** 탭 → *공공데이터 업데이트* → **Run workflow**를 누릅니다.

직접 실행하려면:

```bash
NEIS_API_KEY=... SCHOOLINFO_API_KEY=... \
  python3 scripts/update_data.py            # 서울, 경기, 인천 모두
```

`python3 scripts/update_data.py 서울특별시`처럼 시도 하나만 돌릴 수도 있습니다. 다른 시도는 `scripts/update_data.py`의 `PROVINCES`에 나이스 교육청 코드와 학교알리미 시도·시군구 코드를 넣어 추가합니다.

## 사이트 미리 보기

```bash
python3 -m http.server 8000
```

브라우저에서 <http://localhost:8000> 을 엽니다. 별도 설치가 필요 없는 정적 사이트라 GitHub Pages로 무료 공개할 수 있습니다.

## 개원 상담 신청 사이트

`intake.html`은 상담받을 분이 직접 개원 보고서 만들기와 같은 항목(과목, 대상, 예산, 임대료 한도, 경력, 실적, 원하는 시·구, 신도시만)을 넣는 신청 화면입니다. 사주(생년월일, 출생시간, 양력·음력, 성별)는 "사주 풀이도 받고 싶다"를 고른 분만 넣고, 개인정보 수집·이용 동의를 받아야 보낼 수 있습니다.

신청은 운영자 본인의 **구글 시트**에 한 줄씩 쌓이고, 학원 입지 가이드의 **받은 상담 신청** 칸에서 불러와 버튼 하나로 개원 보고서(사주 풀이 포함)를 만듭니다. 신청 내용은 이 저장소에 올라가지 않습니다.

처음 한 번만 설정합니다.

1. 구글 시트를 새로 만들고 **확장 프로그램 → Apps Script**를 엽니다. `scripts/intake-sheet.gs` 내용을 통째로 붙여 넣고, 맨 위 `READ_KEY`를 남이 짐작하기 어려운 12자 이상 비밀번호로 바꾼 뒤 저장합니다.
2. **배포 → 새 배포 → 유형: 웹 앱**, 실행 계정 **나**, 액세스 권한 **모든 사용자**로 배포하고 권한을 허용합니다. 나오는 웹 앱 주소(`https://script.google.com/macros/s/…/exec`)를 복사합니다.
3. `intake-config.js`의 `window.INTAKE_URL = ""` 따옴표 안에 그 주소를 넣습니다.
4. 저장소 **Settings → Pages**에서 기본 브랜치의 루트(`/`)로 GitHub Pages를 켭니다. 신청 주소는 `https://newclear2222-idea.github.io/ACADEMY-search/intake.html`입니다.
5. 가이드의 **받은 상담 신청**을 열고 웹 앱 주소와 비밀번호를 넣어 **신청 불러오기**를 누릅니다. 이 브라우저가 기억합니다. 화면에서 바깥 주소 연결이 막혀 불러오지 못하면, 시트에서 그 신청 줄 맨 끝 **원본** 칸을 복사해 **직접 붙여넣기**에 넣으면 됩니다.

시트의 **처리 메모** 칸에 적은 내용은 가이드 목록에도 함께 보입니다. `scripts/intake-sheet.gs`를 고치면 Apps Script에서 **배포 관리 → 수정 → 새 버전**으로 다시 배포해야 반영됩니다.

## 동네 알림

가이드 동별 카드의 **🔔 알림 받기**를 누른 동네를 매일 아침 7시에 확인해, 새 소식이 있으면 시트 **알림** 탭에 쌓고 시트 주인의 Gmail로 보냅니다. 원장님 화면에서만 보입니다.

- **학원 문 닫음·휴원**: 교육청 학원 목록에서 빠지거나 휴원으로 바뀐 학원·교습소(모든 분야). 학원을 하던 자리가 빌 수 있다는 뜻입니다.
- **새 학원**: 그 동에 새로 생긴 입시·보습 학원·교습소.
- **LH 상가 공고**: 그 시·구나 동 이름이 공고명에 들어간 LH 상가 공고(공공데이터포털 'LH 분양임대공고문 조회 서비스').

일반 상가 매물(네이버 부동산, 네모 등)은 공개 API가 없고 수집을 막고 있어 넣지 않았습니다. 처음 고른 동은 그날 학원 목록만 저장하고 다음 날부터 알립니다. 교육청 자료가 덜 와서 한 동의 학원이 30% 넘게(5곳 초과) 한꺼번에 빠지면 그날은 '문 닫음'을 보내지 않습니다.

처음 한 번만 설정합니다.

1. Apps Script에 `scripts/intake-sheet.gs` 새 내용을 통째로 붙여 넣되, 맨 위 `READ_KEY`는 쓰던 비밀번호로 그대로 둡니다. 저장 후 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전 → 배포**를 누르고, Gmail 보내기 권한을 묻으면 허용합니다. 주소는 그대로입니다.
2. 저장소 **Settings → Secrets and variables → Actions**에 `SHEET_KEY`를 만들고 값에 그 `READ_KEY`를 넣습니다.
3. (LH 상가 공고도 받으려면) 공공데이터포털에서 **한국토지주택공사_분양임대공고문 조회 서비스**를 활용신청합니다. 키는 쓰던 `DATA_GO_KR_KEY` 그대로입니다.
4. 가이드에서 동네를 고른 뒤 **Actions → 동네 알림 → Run workflow**로 한 번 돌려 보면 시트에 **알림지역·알림·알림상태** 탭이 생깁니다.

알림 동네는 시트 **알림지역** 탭에서 직접 줄을 더하거나 지워도 됩니다(지역 칸은 `서울-노원구`처럼 씁니다).

## 계산 방법과 한계

- 학생 수는 그 동에 있는 초·중·고등학교 재학생 수의 합입니다. 학교가 없는 동은 0명으로 나옵니다.
- 학원은 '입시·검정 및 보습' 분야로 등록된 학원·교습소 중 영업 중인 곳만 셉니다. 과목은 학원명과 교습과정에 '수학', '영어'가 들어간 곳입니다.
- 동은 학교와 학원 주소에 나오는 법정동(예: 중계동)이나 읍·면 기준입니다. 경기도의 구가 있는 시(수원, 성남 등)는 시 단위로 묶습니다.
- 임대료, 유동인구, 학교와의 거리, 학원가 선호도는 아직 반영하지 않았습니다.

## 사주(만세력) 계산기

`saju/lib/saju-profile.ts`는 원장일지 사이트에서 쓰던 만세력 계산기를 그대로 옮긴 것입니다(계산 규칙 변경 금지). 사이트는 이를 묶은 `saju.js`를 보고서 만들기에서 생년월일을 넣었을 때만 불러옵니다. 입력한 생년월일은 화면 안에서만 계산하고 어디에도 저장하지 않습니다.

```
cd saju
npm ci          # 라이브러리 버전은 package.json에 정확히 고정
npm test        # 확인값 6개 대조
npm run build   # ../saju.js 다시 만들기
```
