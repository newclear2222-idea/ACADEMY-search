# 학원 입지 가이드

학원을 새로 여는 분들이 **어느 동네에서 열면 좋을지** 비교해 볼 수 있는 사이트입니다.
동네별 **학생 수**(초·중·고)와 **기존 학원 수**(수학, 영어, 입시·보습 전체)를 합쳐
"학원 1곳당 학생 수"를 계산하고, 경쟁이 덜한 동네부터 보여줍니다.

**서울 25개 구, 경기 31개 시·군, 인천 전체**를 다룹니다. 지역 안에서는 동·읍·면별로 비교합니다.

## 쓰는 공공데이터

| 무엇 | 어디서 | GitHub Secret 이름 |
| --- | --- | --- |
| 학원 목록 (주소, 분야, 교습과정) | [나이스 교육정보 개방포털](https://open.neis.go.kr) 학원교습소정보 API | `NEIS_API_KEY` |
| 학생 수 (학교별 재학생) | [학교알리미](https://www.schoolinfo.go.kr) OpenAPI 학년별·학급별 학생수 | `SCHOOLINFO_API_KEY` |

두 인증키 모두 무료입니다. 키는 저장소 **Settings → Secrets and variables → Actions**에 넣고, 코드나 파일에는 절대 적지 않습니다.

## 자동 업데이트

`.github/workflows/update-data.yml`이 **매달 5일** 두 API에서 최신 데이터를 받아 `data/` 아래 지역별 파일(예: `data/서울-노원구.json`, `data/경기-수원시.json`)과 `data/regions.json`을 새로 만들고 저장소에 저장합니다.
기다리지 않고 바로 돌리려면 저장소의 **Actions** 탭 → *공공데이터 업데이트* → **Run workflow**를 누릅니다.

직접 실행하려면:

```bash
NEIS_API_KEY=... SCHOOLINFO_API_KEY=... \
  python3 scripts/update_data.py            # 서울, 경기, 인천 모두
```

`python3 scripts/update_data.py 서울특별시`처럼 시도 하나만 돌릴 수도 있습니다. 다른 시도는 `scripts/update_data.py`의 `PROVINCES`에 나이스 교육청 코드와 학교알리미 시도·시군구 코드를 넣어 추가합니다.

## 사이트 미리 보기

```bash
python3 -m http.server 8000
```

브라우저에서 <http://localhost:8000> 을 엽니다. 별도 설치가 필요 없는 정적 사이트라 GitHub Pages로 무료 공개할 수 있습니다.

## 계산 방법과 한계

- 학생 수는 그 동에 있는 초·중·고등학교 재학생 수의 합입니다. 학교가 없는 동은 0명으로 나옵니다.
- 학원은 '입시·검정 및 보습' 분야로 등록된 학원·교습소 중 영업 중인 곳만 셉니다. 과목은 학원명과 교습과정에 '수학', '영어'가 들어간 곳입니다.
- 동은 학교와 학원 주소에 나오는 법정동(예: 중계동)이나 읍·면 기준입니다. 경기도의 구가 있는 시(수원, 성남 등)는 시 단위로 묶습니다.
- 임대료, 유동인구, 학교와의 거리, 학원가 선호도는 아직 반영하지 않았습니다.
