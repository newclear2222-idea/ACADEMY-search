# 학원 입지 가이드

학원을 새로 여는 분들이 **어느 동네에서 열면 좋을지** 비교해 볼 수 있는 사이트입니다.
동네별 **학생 수**(초·중·고)와 **기존 학원 수**(수학, 영어, 입시·보습 전체)를 합쳐
"학원 1곳당 학생 수"를 계산하고, 경쟁이 덜한 동네부터 보여줍니다.

첫 버전은 **서울특별시 노원구**를 대상으로 합니다.

## 쓰는 공공데이터

| 무엇 | 어디서 | 파일 |
| --- | --- | --- |
| 학원 목록 (위치, 분야, 교습과정) | [나이스 교육정보 개방포털](https://open.neis.go.kr) → 학원교습소정보 | CSV 또는 엑셀 |
| 학생 수 (만 6~17세 인구) | [행정안전부 주민등록 인구통계](https://jumin.mois.go.kr) → 연령별 인구현황 | CSV |

### 파일 받는 법

1. **학원 목록**: 나이스 교육정보 개방포털에서 '학원교습소정보'를 검색하고, 시도교육청을 *서울특별시교육청*으로 골라 CSV(또는 엑셀)로 내려받습니다.
2. **연령별 인구**: 주민등록 인구통계 사이트의 '연령별 인구현황'에서
   - 행정구역: 서울특별시 → 노원구 → *전체 읍면동*
   - 연령 구분 단위: **1세**, 만 연령구분: 0~100세 이상
   - 성별: 계만 선택해도 됩니다
   - 조회 후 CSV 파일로 내려받습니다.

두 파일 모두 API 키 없이 받을 수 있습니다.

## 데이터 반영하기

받은 파일을 `data/raw/` 폴더에 두고 다음을 실행합니다. (`data/raw/`는 저장소에 올라가지 않습니다.)

```bash
python3 scripts/build_data.py --gu 노원구 \
  --academies data/raw/학원교습소정보.csv \
  --population data/raw/연령별인구현황.csv \
  --base-date "2026년 9월"
```

그러면 `data/노원구.json`과 `data/regions.json`이 만들어지고, 사이트 지역 목록에 노원구가 나타납니다.
다른 구도 `--gu` 값만 바꿔 같은 방법으로 추가할 수 있습니다.

## 사이트 미리 보기

```bash
python3 -m http.server 8000
```

브라우저에서 <http://localhost:8000> 을 엽니다. 별도 설치가 필요 없는 정적 사이트라 GitHub Pages로 무료 공개할 수 있습니다.

## 계산 방법과 한계

- 학생 수는 주민등록 기준 만 나이로 나눕니다: 초등 6~11세, 중등 12~14세, 고등 15~17세.
- 학원은 '입시·검정 및 보습' 분야로 등록된 학원·교습소 중 영업 중인 곳만 셉니다. 과목은 학원명과 교습과정에 '수학', '영어'가 들어간 곳입니다.
- 학원 주소는 법정동(예: 중계동), 인구 통계는 행정동(예: 중계1동, 중계2·3동) 단위라서 같은 이름의 동끼리 묶어 비교합니다.
- 임대료, 유동인구, 학교와의 거리, 학원가 선호도는 아직 반영하지 않았습니다.
